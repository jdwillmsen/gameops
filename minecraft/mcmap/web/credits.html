Credits

The map stands on other people’s work. Thank you to all of them. Licences are as the authors state them.

The game

Minecraft is made by Mojang and Microsoft, who have no part in this map. The map reads the server’s own world.

The mob and block pictures on the map are Mojang’s own artwork. They are not part of the map’s code or its downloads: the running map fetches them from Mojang’s public sample files, keeps them on its own disk, and shows them only to logged-in players. They remain © Mojang AB, all rights reserved.

Terrain drawing

uNmINeD draws the terrain tiles. It is closed-source software, free for non-commercial use but not to be redistributed, so the map downloads it from its author when it first needs it.

In the browser

  • Leaflet 1.9.4, the map widget: BSD 2-Clause licence, © Volodymyr Agafonkin and CloudMade.

In the server

The server is written in Go and uses these libraries:

  • gophertunnel (Sandertv), beorn7/perks, cespare/xxhash: MIT licence.
  • Prometheus client_golang, client_model, common and procfs: Apache 2.0 licence.
  • df-mc/goleveldb: BSD 2-Clause licence.
  • golang/snappy, munnerz/goautoneg, golang.org/x/sys, google.golang.org/protobuf: BSD 3-Clause licence.
  • klauspost/compress: BSD 3-Clause licence, with some parts under Apache 2.0 and MIT.
